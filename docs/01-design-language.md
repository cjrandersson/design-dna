# 01 — Design language

This document captures recurring visual tendencies. They are **defaults, not laws**. A specific project may override them, but an agent should never override them accidentally.

## 1. The baseline feeling

The recurring target is usually some combination of:

- minimal
- quiet
- precise
- tactile
- editorial
- modular
- slightly strange
- engineered without feeling corporate
- polished without becoming sterile
- characterful without visual noise

A useful shorthand:

> Calm structure + strong character + one deliberate irregularity.

## 2. Minimalism does not mean removing capability

Minimalism means reducing competition for attention.

A complex tool may still contain many functions, but:

- the important action should dominate
- secondary controls should recede
- contextual controls should appear when useful
- empty space should clarify hierarchy
- related functions should feel physically grouped

Avoid interpreting “minimal” as:

- generic white SaaS
- tiny grey text everywhere
- hiding important functions
- removing visual identity
- flattening everything into identical cards

## 3. Precision + accident

A recurring tension is between disciplined structure and controlled imperfection.

Useful combinations:

- strict grid + irregular typography
- precise geometry + organic edge
- clean composition + degraded image
- restrained palette + one odd accent
- polished surface + DIY print texture
- engineered interface + playful behaviour

The irregularity should feel intentional, not sloppy.

## 4. Materiality

When appropriate, favour surfaces that feel physical without becoming skeuomorphic.

Recurring material cues:

- matte
- ceramic
- satin metal
- translucent glass
- paper
- grain
- warm mineral surfaces
- subtle texture
- embossed / debossed restraint

Avoid defaulting to:

- glossy gradients
- fake glassmorphism
- chrome sci-fi
- photorealistic hardware controls
- heavy shadows
- decorative 3D with no functional purpose

## 5. Geometry

Prefer shapes that feel intentional and coherent across the system.

Common tendencies:

- soft but controlled radii
- modular blocks
- strong silhouette
- generous margins around important controls
- rounded forms where they improve tactility
- occasional geometric interruption for character

Do not randomly mix:

- sharp cards
- pill buttons
- huge rounded panels
- floating blobs

unless the contrast is intentional and documented.

## 6. Typography

Typography should create identity and hierarchy, not merely carry text.

Prefer:

- clear scale differences
- confident headings
- restrained body copy
- editorial spacing
- typography that can become graphic material
- occasional oversized or cropped display type when appropriate

Avoid:

- generic dashboard typography
- five barely different text sizes
- weak hierarchy
- unnecessary all-caps
- decorative fonts used everywhere

Experimental typography is welcome when the project supports it, but function and readability remain deliberate.

## 7. Colour

Colour should have a job.

Good uses:

- state
- focus
- hierarchy
- category
- signal flow
- emotion
- one memorable accent

Prefer restrained palettes with intentional contrast.

Avoid rainbow systems created simply because many colours are available.

Status colour should remain semantic and consistent.

## 8. Density and whitespace

Whitespace is structural, not decorative.

Use it to:

- separate global from local controls
- protect important actions
- create pacing
- make dense interfaces readable
- establish calm

Compact is good when information remains legible.

Cramped is not.

## 9. Interaction

Interfaces should feel direct and tactile.

Prefer:

- obvious cause and effect
- visible state changes
- immediate feedback
- large playable targets where interaction is frequent
- controls that reveal behaviour rather than hide it
- progressive disclosure for complexity

Avoid:

- invisible modes
- ambiguous click targets
- animation that delays action
- decorative interactions without functional meaning

## 10. Instrument-like interfaces

For creative tools, audio software and experimental systems, the interface should often feel like an **instrument**, not an admin panel.

Useful traits:

- visible signal flow
- waveform-first or material-first layouts
- modulation / generative behaviour made visible
- macro controls above dense micro-control
- contextual depth
- direct manipulation
- restrained state colour

Avoid:

- fake screws
- faux rack hardware
- photorealistic knobs
- unnecessary neon
- dashboard cards everywhere

## 11. Packaging / physical product direction

Recurring physical design tendencies include:

- Japanese-influenced restraint
- Scandinavian clarity
- negative space
- translucent or minimally obstructed materials
- tactile matte finishes
- reduced branding
- unexpected label shape / placement
- strong use of form and material before decoration

The result may feel luxurious, but should not become conventional luxury signalling.

## 12. Anti-patterns

Unless intentionally requested, avoid drifting toward:

- generic SaaS dashboard aesthetics
- excessive cards and borders
- decorative gradients
- fake hardware
- glassmorphism by default
- corporate blue
- placeholder icons / emojis replacing designed assets
- inconsistent typography
- arbitrary new component styles
- over-simplification that removes character
- retro skeuomorphism
- visual effects with no functional or conceptual reason

## 13. Preservation rule

Once a visual direction is approved, treat these as protected assets unless explicitly changed:

- typography
- hierarchy
- image language
- spacing logic
- component architecture
- colour behaviour
- interaction model
- key graphical motifs

Iteration should improve the design, not silently restart it.
